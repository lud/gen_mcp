# Deduplicate Suite repo helpers

From the code review of spec 036. In `lib/gen_mcp/suite.ex`:

- `stream_resource_repos/3`, `stream_prompt_repos/3` and `stream_skill_repos/3`
  are three copies of the same stream-and-expand helper.
- `handle_list_skills/3` + `list_skills/3` copy `handle_list_resources/3` +
  `list_resources/3` (cursor decoding, `paginate_repos`, cursor encoding).

Factor each pair into one helper parameterized by the extension callback, the
`expand` function and the result builder. Behaviour must not change.

Done when each helper exists once and the test suite passes unchanged.
